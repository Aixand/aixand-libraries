# Security reports

Report suspected vulnerabilities privately to [corporate@aixand.org](mailto:corporate@aixand.org)
with the subject `Aixand libraries security report`. Do not disclose vulnerabilities
in public issues or pull requests. Include the affected library and version,
platform, potential impact, and minimal reproduction using synthetic data.
Remove credentials and unrelated personal information. Ask how to share sensitive
material before sending it.

Response and remediation timing depend on severity and maintainer capacity.
Please coordinate disclosure so affected integrators can receive a fix or mitigation.
For ordinary bugs and usage questions, use the integrating product's support channel
or issue tracker; see [reporting guidance](docs/reporting.md).
