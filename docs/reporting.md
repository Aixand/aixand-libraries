# Support and reporting

Report bugs, documentation problems, feature requests, and usage questions through
the support channel or issue tracker of the product integrating these libraries.
That product's maintainers have the application context and can investigate and
coordinate library fixes. Include the product version, affected library/version
when known, platform, expected behavior, and a minimal reproduction. Search the
integrating product's existing reports first. Ordinary reports do not belong in
this library repository.

External contributions and pull requests are not currently accepted, including
code, documentation fixes, and cleanup. Maintainer capacity is limited; please
use the integrating product's reporting channel instead of submitting a patch.
Development guides and templates support internal maintenance and integration;
they are not an invitation to contribute. Responses and fixes depend on availability.

Security vulnerabilities are an exception: report them directly and privately
using the [security policy](../SECURITY.md).
